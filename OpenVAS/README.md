# OpenVAS — Vulnerability Assessment

## Executive Summary

This project demonstrates practical vulnerability management using the Greenbone OpenVAS framework, an industry-standard open-source vulnerability scanner used by security teams worldwide.

The work covers the full assessment workflow: installing and configuring the OpenVAS/Greenbone Security Assistant on Linux, targeting network devices by IP address, executing automated scans to enumerate CVEs and assess service exposure, and producing structured vulnerability reports. The project also documents the real-world troubleshooting process — resolving CLI installation issues, dependency conflicts, and service daemon configuration — reflecting the practical engineering skills required in a live SOC or vulnerability management role.

Scan results and supporting screenshots are retained as evidence of findings, and the raw XML report provides machine-readable output suitable for integration into vulnerability tracking workflows.

**Key skills demonstrated:** vulnerability scanning and management, OpenVAS/Greenbone configuration, CVE identification, Linux CLI administration, network device assessment, report generation, and security tooling troubleshooting.
